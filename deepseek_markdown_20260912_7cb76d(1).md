# Contribuer à DarkMBTI

Merci de l'intérêt. Quelques règles simples avant d'ouvrir une issue ou
une pull request.

## Philosophie du projet

DarkMBTI est un outil **minimaliste**, **local**, **sans dépendance**,
et **bienveillant**. Toute contribution doit respecter ces quatre
principes.

## Ce qui sera refusé

- Toute fonctionnalité de télémétrie, d'envoi réseau, de compte en ligne
- Toute fonctionnalité d'évaluation d'autrui, de profilage, de scoring
  de "dangerosité" ou de "fiabilité"
- Toute intégration d'IA externe (le projet reste offline et sans
  dépendance)
- Tout contenu qui juge, classe, ou stigmatise des personnes

## Ce qui sera considéré

- Corrections de bugs
- Améliorations de la lisibilité du code
- Nouvelles formulations de questions, si elles restent neutres
- Nouvelles options qui respectent la philosophie
- Traductions (le français est la langue de référence)

## Signaler un bug

Ouvre une issue avec :
- Ta version de Python (`python --version`)
- Ton système (Windows, macOS, Linux)
- La commande exacte que tu as lancée
- Le comportement attendu et le comportement observé
- Le message d'erreur complet s'il y en a un

## Proposer une contribution

1. Fork le dépôt
2. Crée une branche `feature/ma-contribution`
3. Teste ton code sous Python 3.9 minimum
4. Ouvre une pull request en expliquant *pourquoi*, pas seulement *quoi*

## Style de code

- PEP 8, sans exception
- Type hints partout où c'est possible
- Pas de dépendance externe
- Commentaires en français pour le contenu utilisateur, en anglais si
  le code s'y prête mieux

## Code de conduite

Sois respectueux. Pas de jugement sur les personnes. Ce projet parle
d'auto-observation, pas d'évaluation.
